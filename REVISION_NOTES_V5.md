# Revision Notes — Version 5

## Removed narrative components

- Removed the narrative-only checkbox from both analytical panels.
- Removed linked-narrative sections and controls.
- Removed narrative KPIs, narrative hover fields, and narrative export fields.
- Removed narrative flags and identifiers from every compact financial row.
- Removed all narrative data chunks, manifests, metadata, build logic, validation logic, and documentation references.

## Added Quick Report

- Added a default decision-oriented interaction mode.
- Added single-area and two-scenario comparison reports.
- Added shared geography, financial-measure, and trend-basis controls.
- Added all-period, latest one-year, latest three-year, latest five-year, and custom-quarter time horizons.
- Added optional year, disaster type, grantee, project, and activity-type filters.
- Added a one-page report containing four indicators, a map, funding trend, top-five ranking, rule-based takeaways, and data-quality notes.
- Added report PNG, print/save-PDF, and aggregate CSV exports.

## Retained analytical functions

- Two independent Explore & Compare panels.
- Seven hierarchical filters per panel.
- State, county/county-equivalent, city/place, and urban-area analysis.
- Five financial measures and quarterly/cumulative timelines.
- Aggregate CSV and figure downloads.

## Deployment

The application remains fully compatible with GitHub Pages and includes a fully self-contained HTML edition for direct local opening or one-file deployment.
